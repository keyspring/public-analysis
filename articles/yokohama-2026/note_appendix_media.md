# 追補：選挙戦のメディアと街頭活動は、どこまで数えられたか

※ 本稿は既存の記事（横浜市長選2026を数字で読む）への追補の草稿です。既存記事は変更していません。投稿・公開は行いません。

選挙結果は確定しました。では、選挙戦の中で候補者はどれだけ情報に触れられたのでしょうか。今回、テレビ、新聞、動画、街頭活動の記録を集めました。そこで分かったことと、分からなかったことを整理します。

## 1. 期日前投票は増えたが、比率は下がった

2025年の期日前投票は、公式PDFで確認した速報で448,839人でした。2026年は報道値で470,980人です。差は22,141人の増加です。

一方、投票者総数は2025年1,292,363人から2026年1,416,233人へ増えました。期日前投票の割合は、2025年の34.73％から2026年の33.26％へ、1.47ポイント下がっています。

ただし、2026年の期日前人数は公式PDFでは確認できていません。確定した数字として扱わないでください。

## 2. 同じ動画の再生数は、同じ意味ではない

tvkが公開した第一声動画は、7候補それぞれ別の日時に公開されました。山本氏は10月4日18時19分、他の6人は22時に公開されています。

2026年10月5日3時55分時点の再生回数は、原沢氏1,281回、福山氏1,219回、山中氏815回、中谷氏479回、藤川氏287回、あさか氏433回、山本氏1,713回でした。

これは選挙期間の総SNS到達ではありません。視聴者の実人数でもありません。公開からの経過時間も候補で違います。候補の強さを比べる根拠にはしないでください。

## 3. 共通の討論会は、動画全体の閲覧数

7候補が出演した討論会は、2回確認できました。10月5日の選挙ドットコム主催は、10月6日時点で約94,000回です。10月10日のReHacQ主催は、10月10日23時30分時点で約154,000回です。

いずれも動画全体の閲覧数です。7人で割ったり、7倍したりして候補別の数字にはできません。2回の観測時点も違います。

## 4. 街頭演説は、予定と実施を分けて数える

候補者公式の予定、有志の記録、本人の実施報告、映像での確認は、性質が違います。

同じ日時で食い違う記録もありました。中谷氏の10月17日17時の場所は、候補者公式の予定では青葉台駅、有志の記録では横浜駅です。両方を実施として足すことはしていません。

定員のある個人演説会も、定員は来場者数ではありません。全期間の演説回数で候補をランキングすることはしていません。

## 5. 数えられなかったもの

テレビの候補別出演時間、新聞の全体の掲載量、ラジオ、X（旧Twitter）の総投稿数、広告支出は、取得できませんでした。欠測は0として扱っていません。

テレビの番組枠は、候補の露出時間ではありません。新聞の記事一覧は選んだ例であり、報道の総量ではありません。
