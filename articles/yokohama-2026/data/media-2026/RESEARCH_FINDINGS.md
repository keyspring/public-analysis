# 横浜市長選2026 選挙戦定量調査（2026-10-19）

**資料台帳：42出典、51測定行、19映像観測行、11テレビ番組枠行、11記事サンプル行、48街頭・個人演説会の記録行。**
これは取材・検索で確保できた標本の行数であり、選挙期間の全件数ではない。

## 速報的に使える発見（データ・事実）

**A. 期日前投票と投票率**

2026年の期日前投票は速報 **470,980人**、2025年は **448,839人**。差 **+22,141人**。しかし有権者全体の投票者数に占める期日前投票者数の比率は、2025年 **34.73％** → 2026年 **33.256％**（**-1.474ポイント**）。期日前投票の絶対数は増えても、投票者全体に占める比率は低下した。出典 S001/S003/S004/S005/S006。これは「速報の期日前人数÷確定投票者総数」の比較であり、最終確定の投票様式別内訳とは異なる。

投票者総数の変化は **+123,870人**。期日前投票者数の変化を差し引いた残差は **+101,729人**（投票者増の **82.13％**）。これは「期日前以外の残余」であり、単純に当日投票だけとは呼ばない。

**B. 7候補に共通のインターネット露出**

10/5 選挙ドットコム主催の討論会（7候補、各主張8分）は **10/6時点約94,000再生**。10/10 ReHacQ討論会（7候補、会全体約140分）は **10/10 23:30時点約154,000再生**。7人全員が出た同じ番組を候補別再生数に7倍配分してはいけない。出典 S009～S012。

**C. 同じtvkチャンネルに並んだ第一声の動画7本**

第三者インデックス「ユーチュラ」の **10/5 03:55時点** のスナップショットに7本の再生数が存在する。`video_observations.csv` の `YT-TVK-` 7行。**山本氏の第一声のみ18:19投稿、他の6候補は22:00投稿なので、03:55時点までの公開時間も異なる**。したがって同一局の初期スナップショットでも厳密な公平比較にはならない。さらに**投票日前の非常に早いスナップショットで、全期間の支持や認知度の代理指標ではない**。視聴者実人数でもない。出典 S013/S014。

**D. 配信の到達数は媒体に強く左右される**

参政党公式で確認できる福山関連動画：10/12センター南駅演説 **89,844再生**、10/14神谷氏との対談 **109,771再生**、10/17桜木町駅演説 **80,084再生**。同一公式チャンネルのほか短尺・紹介動画も収録した。対してArc Timesの山中・藤川・あさか街頭配信は動画単位で **30,644／15,176／24,023再生**（いずれも再生回数スナップショット。日時・配信媒体が一致せず、候補の効果比較には使えない）。中谷×ひろゆき対談は実在を確認したが、閲覧数は取得しておらず **欠測（0ではない）**。出典 S015～S018。

**E. 街頭演説の『回数比較』には危険がある**

中谷氏は10/17予定が **7駅**（S020）。原沢氏は10/11予定が **6駅**（S019）。山本氏は10/8～16に公式掲載の **屋内個人演説会5会場**（S021、施設定員480/480/600/600/517。**定員≠参加者**）。藤川氏の10/10実施報告は小机駅・市が尾駅の **2駅**（S022）。それぞれ母集団の『全期間』でも『同じ日』でもない。**7候補の全期間演説回数ランキングは禁止。** イベント単位行は `street_event_samples.csv` に保存。**注意：10/17の17:00、中谷氏の候補者公式予定は青葉台駅、第三者街宣マップは横浜駅と食い違っている。両方を本人が実施したイベントとして二重計上しない**（`source_conflicts.csv` のC001）。

**F. テレビ・新聞・ラジオの限界**

一部のテレビ番組に選挙の報道があったことは `tv_program_mentions.csv` で特定できるが、番組枠（例：NHKニュース19:00～19:30）は候補の露出秒数ではない。`TVでた蔵` 掲載番組とtvk第一声の二経路を混同しない。新聞の14問アンケートは候補7人分の回答を含むが14本の新聞記事ではない。ラジオ、紙面掲載全数、X全投稿数、広告支出、街頭活動の実施全数などは **取得できなかった**。`missingness_by_candidate.csv` に全7候補×12項目の欠測を明示した。空欄をゼロに変換しない。

**G. 前年から再出馬した2人の票数比較（因果は分からない）**

福山氏：2025年148,236票 → 2026年230,418票、**+82,182票（+55.44％）**。山中氏：2025年663,876票 → 2026年199,746票、**−464,130票（-69.91％）**。他候補の組み合わせ・推薦・投票率・投票時の論点が違い、SNS動画を原因と断定不可。出典 S001/S003/S007。

**H. 出口調査はメディア効果測定ではない**

共同通信：投票所45か所・2,246人への出口調査。SNSや動画サイトの情報重視39％、パワハラ問題重視81％。これらは **閲覧動画数、投票先変更者数、候補者にSNSが与えた票数ではない**。出典 S035。

## 調査できたものと取得できなかったもの

| 分類 | 確認できた測定 | 取得できなかった全数値 |
|---|---|---|
| テレビ | 放送局・番組名・番組枠の一部、tvk第一声7本 | 全番組の候補別出演秒数・件数 |
| 新聞 | 掲載日・媒体・記事サンプル、7候補14問アンケート | 全媒体の紙面記事数・文字数・閲読数 |
| ラジオ | 確実な候補別実測なし | 番組出演総件数・総秒数 |
| YouTube | 同一番組の時点付き再生数、tvk第一声7本、個別動画スナップショット | 全プラットフォーム・全動画の同一時点閲覧数、ユニーク視聴者 |
| X・SNS | 公式チャンネル投稿の一部 | 候補7人の投稿総数・フォロワー推移・インプレッション |
| 演説 | 公式日程と映像に残るサンプル | 全期間の実施演説総回数と各会場の実入場者 |
| 広告 | 選挙日程は確認 | 候補別媒体別支出額・配信インプレッション |

## 重要な研究上の禁止事項

- 再生回数は投票者数・ユニーク人間数ではない。重複配信は合算しない。
- 個人演説会の会場**定員**を観客数にしない。
- 予定を実施実績に変えない。`crowd_` 由来を候補の公式日誌と同列にしない。**中谷氏10/17 17:00の青葉台駅（公式予定）と横浜駅（有志投稿）の食い違いを`source_conflicts.csv`で示し、実行2件として合算しない。**
- 取材選定した記事本数を新聞の報道総量として表示しない。
- テレビの番組全体の放送分数を候補の露出分数として計算しない。
- 欠測値nullを0として棒グラフ化しない。
- 2025と2026の候補者得票の差から、特定媒体・政党支持・演説回数が当落原因であったと主張しない。

## 検証用ファイルの使い分け

- `source_ledger.csv`：独立した一次資料や時点付き二次資料へのURL一覧
- `numeric_observations.csv`：数字の出所、測定時点、単位、母集団
- `video_observations.csv`：動画固有の再生数、媒体、公開日と比較可否
- `street_event_samples.csv`：予定/実施/第三者記録を区別した街頭等の実例
- `tv_program_mentions.csv`：確認できる番組枠のみ、候補者露出秒数は空欄
- `press_story_samples.csv`：重複記事をなるべく外した例示記事
- `missingness_by_candidate.csv`：全数比較の欠測理由
- `computed_summary.json`：再計算済み指標
- `evidence_coverage_not_comparable.csv`：証拠サンプルの所在、**活動量ランキングに使わない**
- `source_conflicts.csv`：公式予定と有志記録の矛盾、二重計上を防ぐ

一次資料と二次資料の強さを列別に記録した。今日の時点で公開資料から全候補のTV・ラジオ・新聞・SNS露出総量を完全に取得したとは主張しない。徹底検索しても、ソースが存在しない数字を埋めないのが重要。
