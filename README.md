# public-analysis

データ分析記事とインタラクティブ表示を公開するリポジトリです。GitHub Pagesで配信しています。

## 掲載中の記事

- [横浜市長選2026｜18区×7候補 インタラクティブ分析](articles/yokohama-2026/)

## 出典と注意

- 候補者別得票、区別得票、投票率は横浜市選挙管理委員会の公式結果表（2026年10月18日執行 横浜市長選挙）による。
- 出口調査は共同通信の報道による標本調査であり、確定得票とは別物。
- 割合は原則として公式票数から再計算し、小数第2位に丸めている。
- サイトはブラウザだけで動作し、外部APIや計測タグを使わない。
- 政党や候補者への投票を勧めるものではない。

## 記事の追加

新しい記事は `articles/<記事名>/` に置き、ルートの `index.html` にリンクを1行追加する。更新は作業ブランチとPull Requestで行い、本人の確認後にmainへ統合する。
